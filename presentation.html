Motivation & Background

Problem Statement & Motivation

⚠️ Road Safety Crises
  • 90%+ Accidents: Caused by driver distraction, microsleep, and erratic maneuvers.
  • False Warning Fatigue: Standard systems trigger annoying beeps during necessary emergency swerves.
  • Sensor Dropouts: GPS degrades heavily in tunnels and urban canyons (high HDOP).
🛑 General OS Inadequacy
  • Non-Deterministic Jitter: Desktop OSs (Windows/Linux) have scheduler latency spikes unsafe for vehicles.
  • Heavy Overhead: Requires gigabytes of RAM and complex graphic abstractions.
  • No Raw I/O Control: Applications cannot deterministically access raw hardware timers.
✅ Engineered Solution
  • Bare-Metal 32-Bit Micro-Kernel: Sub-millisecond hardware interrupt response.
  • Atomic Spinlocks & IPC: Protected inter-task messaging between Sensor and Safety tasks.
  • Context-Aware Fusion: Dynamic HDOP sensor weighting and road context evaluation.
System Design

Dual-Tier System Architecture

Tier 1: Bare-Metal x86 Kernel (C & Assembly)
  • Multiboot Bootstrap: GRUB boots kernel into 32-bit flat protected mode (Code: 0x08, Data: 0x10).
  • IDT & 8259 PIC Remap: Hardware IRQ0 (Timer @ 100Hz) and IRQ1 (Keyboard ISR).
  • Round-Robin Task Scheduler: Dispatches SENSOR, SAFETY, and DISPLAY tasks every timer tick.
  • Atomic Spinlocks: Mutual exclusion via atomic x86 xchgl assembly instructions.
  • VGA Video Driver: Real-time text mode rendering at memory address 0xB8000.
Tier 2: Context-Aware Analytics & Fusion
  • Butterworth Noise Filter: 2nd order zero-phase digital low-pass filtering (cutoff = 0.15).
  • Adaptive Speed Fusion: Dynamically calculates weights for GPS, OBD-II, and IMU based on HDOP.
  • Driver Baseline Calibration: Initial 20-sample observation window constructs habit benchmarks.
  • Constraint Engine: Immediate hard boundary triggers for Speed > 60 km/h and G-Force > 0.8g.
  • Event Classification: Differentiates NORMAL, AGGRESSIVE, POTHOLE AVOIDING, and DEFENSIVE.

/* Remap 8259 PIC to INT 32-47 */
static void pic_remap(void) {
    outb(0x20, 0x11); io_wait();
    outb(0xA0, 0x11); io_wait();
    outb(0x21, 0x20); /* Master base: 32 */
    outb(0xA1, 0x28); /* Slave base: 40 */
    outb(0x21, 0xFC); /* Unmask IRQ0 & IRQ1 */
}

/* IDT Init with Code Selector 0x08 */
for (int i = 0; i < 256; i++) {
    idt_set_gate(i, (uint32_t)default_interrupt, 0x08, 0x8E);
}
idt_set_gate(32, (uint32_t)timer_interrupt, 0x08, 0x8E);
idt_set_gate(33, (uint32_t)keyboard_interrupt, 0x08, 0x8E);

void timer_init(void) {
    /* 1.193182 MHz / 100 = 11931 divisor */
    uint32_t divisor = 1193182 / 100;
    outb(0x43, 0x36); /* Mode 3 Square Wave */
    outb(0x40, (uint8_t)(divisor & 0xFF));
    outb(0x40, (uint8_t)((divisor >> 8) & 0xFF));
}

void scheduler_tick(void) {
    int total = task_count();
    if (total == 0) return;

    ticks++;
    current_task = (current_task + 1) % total;
    task_run(current_task); /* Round-Robin Step */
}

Code & Execution Flowchart: Atomic Spinlocks & IPC

C & Assembly Implementation (sync.c & ipc.c)
void spinlock_acquire(spinlock_t *lock) {
    uint32_t value;
    do {
        __asm__ volatile (
            "xchgl %0, %1"
            : "=r"(value), "+m"(lock->locked)
            : "0"(1)
            : "memory"
        );
    } while (value != 0);
}

int ipc_send(int sender, int receiver, uint32_t data) {
    spinlock_acquire(&ipc_lock);
    if (queue_count >= IPC_QUEUE_SIZE) {
        spinlock_release(&ipc_lock); return -1;
    }
    queue[queue_tail] = (ipc_message_t){sender, receiver, data};
    queue_tail = (queue_tail + 1) % IPC_QUEUE_SIZE;
    queue_count++;
    spinlock_release(&ipc_lock);
    return 0;
}
Atomic Synchronization Flowchart
Step 1: Lock Request Task calls spinlock_acquire(); executes atomic xchgl.
▼
Step 2: Mutual Exclusion Check If lock was 1, CPU loops; if 0, lock acquired without preemption race.
▼
Step 3: Enqueue Critical Section Writes message to 16-slot circular FIFO buffer and advances tail pointer.
▼
Step 4: Lock Release & Dequeue Sets locked = 0 with memory barrier; allows Safety task to read.

# Butterworth Low-Pass Filter
def low_pass_filter(data, cutoff=0.15, order=2):
    b, a = butter(order, cutoff, btype="low")
    return filtfilt(b, a, data) # Zero phase delay

# Adaptive Speed Fusion
def calculate_weights(gps_hdop):
    if gps_hdop <= 2.0:
        return 0.40, 0.40, 0.20, "HIGH"    # Good Sky
    elif gps_hdop <= 5.0:
        return 0.25, 0.45, 0.30, "MEDIUM"  # Suburban
    else:
        return 0.10, 0.60, 0.30, "LOW"     # Tunnel

def fuse_speed(gps_spd, obd_spd, imu_spd, hdop):
    w_gps, w_obd, w_imu, rel = calculate_weights(hdop)
    fused = (gps_spd*w_gps + obd_spd*w_obd + imu_spd*w_imu)
    return fused, w_gps, w_obd, w_imu, rel

Code & Decision Flowchart: Driver Baseline & Classifier

Python Implementation (baseline & classifier)
# Baseline Habit Calibration
class DriverBaseline:
    def calibrate(self, df):
        self.avg_accel = df["filtered_acceleration"].mean()
        self.avg_gyro = df["filtered_gyro"].mean()
        self.avg_speed = df["obd_speed"].mean()

    def get_deviation(self, accel):
        return abs(accel - self.avg_accel)

# Context-Aware Classifier
def classify_event(accel, steer, context, safety_ok):
    if context["pothole"]:
        return "POTHOLE AVOIDING"
    if context["obstacle"]:
        return "JUSTIFIABLE / DEFENSIVE"
    if not safety_ok:
        return "AGGRESSIVE"
    if abs(steer) > 25:
        return "DEFENSIVE" if context["road_type"]=="curve" else "AGGRESSIVE"
    return "NORMAL"

▼
